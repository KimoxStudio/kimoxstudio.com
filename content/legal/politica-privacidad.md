## 2. Datos personales tratados

Kimox Studio puede tratar datos personales facilitados por el usuario a través del formulario de contacto, así como determinados datos técnicos obtenidos automáticamente durante la utilización del sitio web.

A través del formulario de contacto pueden tratarse los siguientes datos:

* Nombre.
* Dirección de correo electrónico.
* Rango o presupuesto aproximado disponible.
* Información incluida por el usuario al describir su idea, necesidades o proyecto.

Además, cuando se utiliza el formulario, se obtiene automáticamente la dirección IP desde la que se realiza la solicitud.

La dirección IP se utiliza con fines de seguridad, prevención de abuso y spam y para limitar temporalmente el número de solicitudes que pueden enviarse desde una misma dirección IP.

El sitio web utiliza además Vercel Web Analytics para obtener estadísticas agregadas sobre el uso general del sitio web.

Vercel Web Analytics funciona sin utilizar cookies para realizar el seguimiento de los visitantes y permite obtener información estadística sobre la utilización del sitio web sin identificar individualmente a los usuarios en las estadísticas proporcionadas a Kimox Studio.

Se recomienda al usuario no introducir en el formulario información personal que no resulte necesaria para gestionar su solicitud y, especialmente, categorías especiales de datos personales.

## 3. Finalidades del tratamiento

Los datos personales y técnicos podrán ser tratados para las siguientes finalidades:

* Recibir y gestionar solicitudes de contacto.
* Responder consultas realizadas por los usuarios.
* Analizar las necesidades generales del proyecto planteado.
* Preparar y facilitar información, propuestas o presupuestos.
* Mantener las comunicaciones necesarias para gestionar una posible relación profesional o contractual.
* Prevenir usos abusivos, automatizados o fraudulentos del formulario.
* Prevenir spam.
* Aplicar límites temporales al número de solicitudes enviadas desde una misma dirección IP.
* Obtener estadísticas agregadas sobre la utilización del sitio web y mejorar su funcionamiento y contenido.

Los datos obtenidos mediante el formulario no serán utilizados para enviar comunicaciones comerciales o newsletters no solicitadas.

## 4. Base jurídica

El tratamiento necesario para responder consultas, solicitudes de presupuesto o propuestas de proyecto se basa, según el caso, en la gestión de la solicitud realizada por el interesado y en la aplicación, a petición de este, de medidas precontractuales.

Cuando resulte necesario, determinados tratamientos podrán basarse en el consentimiento del interesado.

El tratamiento de la dirección IP para prevenir abuso, spam y utilización automatizada del formulario se basa en el interés legítimo de Kimox Studio en proteger la seguridad e integridad de su sitio web y sus sistemas, siempre que sobre dicho interés no prevalezcan los derechos y libertades fundamentales del interesado.

El tratamiento relacionado con Vercel Web Analytics se realiza con la finalidad de obtener estadísticas agregadas sobre el funcionamiento y utilización del sitio web y mejorar los servicios y contenidos ofrecidos.

## 5. Conservación de los datos

Los datos facilitados mediante el formulario serán conservados durante el tiempo necesario para atender la consulta, gestionar la solicitud y mantener las comunicaciones relacionadas con el proyecto.

Cuando se formalice una relación contractual, determinados datos podrán conservarse durante los plazos necesarios para cumplir las obligaciones legales, fiscales y contables aplicables o para atender posibles responsabilidades derivadas de la relación.

La dirección IP utilizada para controlar la frecuencia de envío del formulario se almacena temporalmente en el sistema de limitación de solicitudes durante un máximo de 24 horas para esta finalidad.

Los datos que hayan dejado de ser necesarios serán eliminados o, cuando legalmente corresponda, bloqueados durante los plazos establecidos por la normativa aplicable.

Kimox Studio no vende ni cede a terceros los datos personales obtenidos mediante el formulario con fines comerciales.

Para el funcionamiento del sitio web y la gestión de las solicitudes pueden intervenir proveedores tecnológicos que prestan servicios de alojamiento, infraestructura, correo electrónico, seguridad, prevención de abuso, limitación de solicitudes o analítica.

Entre estos proveedores se encuentran:

* **Upstash**, utilizado para aplicar mecanismos de limitación de solicitudes y prevención de abuso mediante el tratamiento temporal de la dirección IP.

Estos proveedores podrán tratar determinados datos únicamente en la medida necesaria para prestar sus respectivos servicios.

Los datos también podrán comunicarse a administraciones públicas, autoridades u órganos judiciales cuando exista una obligación legal.
