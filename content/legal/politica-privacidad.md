## 2. Datos personales que tratamos

Kimox Studio puede tratar los datos personales que el usuario facilite voluntariamente mediante el formulario de contacto del sitio web.

Actualmente, el formulario puede solicitar:

* Nombre.
* Dirección de correo electrónico.
* Rango o presupuesto aproximado disponible para el proyecto.
* Información proporcionada por el usuario al describir su idea, necesidades o proyecto.

Se recomienda al usuario no incluir en el campo de descripción información personal que no resulte necesaria para atender su solicitud y, especialmente, datos personales sensibles.

## 3. Finalidad del tratamiento

Los datos facilitados serán utilizados para:

* Recibir y gestionar solicitudes de contacto.
* Responder consultas realizadas por los usuarios.
* Analizar las necesidades generales del proyecto planteado.
* Preparar y facilitar información o un presupuesto cuando sea solicitado.
* Mantener las comunicaciones necesarias para gestionar una posible relación profesional o contractual.

Los datos obtenidos mediante el formulario no serán utilizados para enviar comunicaciones publicitarias o newsletters no solicitadas, salvo que en el futuro se solicite de forma independiente el consentimiento correspondiente.

## 4. Legitimación

El tratamiento de los datos necesarios para responder a consultas generales se basa en la gestión de la solicitud realizada por el propio interesado.

Cuando el usuario solicite un presupuesto, propuesta o información con la finalidad de valorar la contratación de los servicios de Kimox Studio, el tratamiento podrá resultar necesario para aplicar medidas precontractuales solicitadas por el interesado.

Cuando resulte necesario, el tratamiento se basará en el consentimiento otorgado por el usuario.

## 5. Conservación de los datos

Los datos personales serán conservados únicamente durante el tiempo necesario para atender la consulta, gestionar la solicitud o mantener las comunicaciones relacionadas con el posible proyecto.

Si finalmente se establece una relación contractual, determinada información podrá conservarse durante los plazos necesarios para cumplir las obligaciones legales, fiscales, contables o para atender posibles responsabilidades derivadas de dicha relación.

Los datos que hayan dejado de ser necesarios serán eliminados o, cuando legalmente corresponda, bloqueados durante los plazos exigidos por la normativa.

## 6. Destinatarios de los datos

Kimox Studio no vende ni cede los datos personales obtenidos mediante el formulario a terceros con fines comerciales.

Los datos podrán ser tratados por proveedores tecnológicos necesarios para el funcionamiento de los servicios utilizados por Kimox Studio, como proveedores de alojamiento web, infraestructura tecnológica o correo electrónico, cuando resulte necesario para prestar dichos servicios.

Asimismo, los datos podrán comunicarse a administraciones públicas, órganos judiciales u otras autoridades cuando exista una obligación legal.

## 7. Transferencias internacionales

Algunos proveedores tecnológicos utilizados para el alojamiento, infraestructura o correo electrónico podrían prestar servicios desde fuera del Espacio Económico Europeo.

Cuando exista una transferencia internacional de datos personales, esta deberá realizarse utilizando alguno de los mecanismos y garantías previstos por la normativa europea de protección de datos.
