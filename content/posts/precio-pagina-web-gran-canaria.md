    ## Los dos precios de partida

    Tenemos dos puntos de partida para webs, y los dos se pueden pagar de una vez o con una cuota mensual:

    - **Landing page: desde 500 € o 80 €/mes.** Una página hecha a mano para presentar tu negocio o una campaña, con diseño a medida y el SEO técnico incluido. Se entrega en 2-3 semanas.
    - **Web con base de datos y panel: desde 1.500 € o 120 €/mes.** Una web completa con base de datos, usuarios y un panel propio para gestionar tu contenido o tu negocio. Con pago único, el hosting del primer año va incluido.

    ## Qué cambia el precio

    El precio de una web con base de datos y panel depende de sus funcionalidades finales. Estas son las preguntas que más mueven el presupuesto:

    - **¿Cuántas cosas tiene que hacer?** Una página que presenta tus servicios con un botón de WhatsApp es una landing. La web de la [Cafetería Bonita Vida](https://cafeteriabonitavida.com), en Schamann, tiene carta online, galería del local, catering y las reseñas de Google integradas. Cada pieza de ese tipo lleva su propio diseño y su propia programación.
    - **¿Entra gente con usuario y contraseña?** En cuanto hay usuarios, datos guardados o un panel para que tú cambies el contenido, pasas de una landing a una web con base de datos y panel.
    - **¿En cuántos idiomas?** Si vendes al turismo, puede que necesites la web en español, en inglés o en otros idiomas, cada uno bien indexado en Google. Cada idioma es otra versión de cada página que hay que preparar y mantener.
    - **¿Con qué se conecta?** Reservas, pagos, una API externa o un modelo de lenguaje. Cada integración se diseña, se programa y se prueba por separado.
    - **¿Partes de cero o ya tienes web?** También mantenemos webs existentes, las migramos a otra tecnología o refactorizamos su código. Lo que cuesta depende del estado en que esté.

    Hay cosas que no suben el precio porque van siempre: el diseño a medida, el SEO técnico (estructura, metadatos, datos estructurados, sitemap y velocidad), una web que cargue rápido en el móvil y el contacto a un toque, sea por teléfono, WhatsApp, formulario o reservas.

    ## Pago único o cuota mensual

    Las dos modalidades cubren el diseño y el desarrollo. Cambia lo que pasa después de publicar.

    Con **pago único** pagas la web una vez. En la web con base de datos y panel, el hosting del primer año va incluido.

    Con la **cuota mensual** (desde 80 €/mes una landing, desde 120 €/mes una web con base de datos), pagas cada mes el diseño y desarrollo, el hosting, el mantenimiento técnico, el soporte con personas reales y las mejoras. Como la web se construye desde cero, hay un compromiso mínimo al empezar; después sigues mes a mes.

    La cuota encaja si prefieres no adelantar 1.500 € y quieres que alguien cuide la web todo el año. El pago único encaja si tienes el presupuesto y ya sabes quién se ocupará de ella después.

    ## Cómo se suma el IGIC

    Publicamos los precios sin IGIC, el impuesto indirecto que grava en Canarias las entregas de bienes y los servicios que prestan empresas y profesionales ([Agencia Tributaria Canaria](https://www3.gobiernodecanarias.org/tributos/atc/w/igic-impuesto-general-indirecto-canario-?ida=44615&prnt=942)). El tipo general es el 7 %, según el [artículo 32 del Decreto Legislativo 1/2025](https://www.gobiernodecanarias.org/boc/2025/207/3598.html), que reúne las normas del IGIC.

    Con el tipo general, una landing de 500 € lleva 35 € de IGIC en la factura, y una web de 1.500 €, 105 €. Cuando compares presupuestos, mira si cada uno incluye el impuesto o no. Si uno lo incluye y otro no, estás comparando cifras distintas.

    ## Qué preguntar antes de aceptar un presupuesto

    Sea con quien sea, estas preguntas evitan sorpresas:

    1. ¿El precio lleva IGIC o no?
    2. ¿Qué pasa con el hosting a partir del segundo año?
    3. ¿Quién se ocupa del mantenimiento y cuánto cuesta?
    4. ¿Cuál es el plazo de entrega, por escrito?
    5. Si pago al mes, ¿hay permanencia? ¿Cuánto dura?
    6. ¿El SEO técnico va incluido o se cobra aparte?
    7. Si un día cambio de proveedor, ¿podrá otro equipo seguir trabajando en la web?

    Nosotros te damos el precio final antes de empezar. El plazo de una landing es de 2-3 semanas; el de una web más grande depende de sus funcionalidades, y te lo damos junto con la propuesta.
